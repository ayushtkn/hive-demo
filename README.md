# Try Apache Hive 🚀

Launch a fully configured, interactive Apache Hive (v4.2.0) environment right in your browser. No installation required!

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayushtkn/hive-demo)

---

### How it works:
1. Click the button above.
2. Log in to GitHub (it uses your free Codespaces quota, not your local machine).
3. Wait about 60 seconds for the container to build.
4. The terminal will automatically pop open and drop you into the Beeline prompt (`0: jdbc:hive2://localhost:10000/>`).
